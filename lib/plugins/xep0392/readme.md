# XEP-0392 — 一致性颜色生成

## 自动行为

纯工具类，不实现 Plugin 接口。其他模块直接 `import { XEP0392 }` 使用。

## API

| 方法 | 说明 |
|------|------|
| `XEP0392.colorize(s)` | 输入字符串 → `Promise<hex_color>`（如 `#FF6B6B`） |

## 算法概要

```
1. 对输入字符串计算 SHA-1 哈希
2. 取低 16 位，映射到 [0, 360] HSLuv 色相
3. 固定饱和度 100、亮度 50
4. 转换 HSLuv → RGB Hex
```

## 注意事项

- 同一输入**永远返回同一颜色**（确定性算法）
- 内置 Map 缓存，重复查询不重新计算
- 典型用途：为 JID/昵称生成固定头像背景色
- 依赖 `hsluv` 库
